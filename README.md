# 🧩 **QR Code Generator in Python**



A simple Python script that generates QR codes from any URL entered by the user.



---



\## 🚀 **Features**

\- Takes a URL input from the user  

\- Generates a QR code image instantly  

\- Saves the QR code to a local folder  

\- Uses the lightweight `qrcode` Python library  



---



\## 🧠 **How to Run**



1\. **Install Dependencies**

&nbsp;  pip install qrcode\[pil]

2\. **Run the Script**

&nbsp;  python qrcode\_generator.py

3\. **Enter a URL**

&nbsp;  When prompted, enter any valid URL (for example):

&nbsp;  https://zencystudiosorg.framer.website/

4\. **Output**

&nbsp;  A file named qrcode.png will be saved automatically in your project folder.
